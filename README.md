# Newzy – News Aggregation Web App

Newzy is a responsive news aggregation web application that displays the latest news articles across multiple categories using a clean and user-friendly interface.

This project focuses on frontend best practices such as API integration, state handling, authentication flow, responsive UI design, and real-world application structure.
